# Embeddings are downloaded separately

Download `glove.6B.zip` from https://nlp.stanford.edu/projects/glove/ and extract only `glove.6B.100d.txt` here. The original 6B release has 400,000 uncased words and 100-dimensional vectors trained on Wikipedia 2014 + Gigaword 5.

The archive is 862,182,613 bytes. No embeddings or archive are included. `.gitignore` excludes local data downloads. Existing local archives may be reused without copying them into this package.
